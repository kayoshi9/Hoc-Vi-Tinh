🔬 Tab Giả lập — Bài 3 Buổi 2: Nhịp tim CPU & RAM qua Task Manager

Mô phỏng giống Windows 10 thật 95% để bé nhận ra ngay trên máy thật. Bé sẽ xem là chính, chỉ cần bấm đúng 3 điểm dừng là qua bài.

① Bấm 3 phím thần thánh
② Mở tab Performance
③ Soi CPU / Memory / Disk
👋 Giáo sư Máy Tính: Bấm nút ▶ Bắt đầu minh họa để mở Task Manager như hacker thật nhé!
BÀN PHÍM GIẢ LẬP — giữ cả 3 phím cùng lúc (có thể bấm phím thật trên máy!)
💡 Mẹo: bấm từng phím giả bằng chuột / ngón tay, hoặc giữ Ctrl + Shift + Esc thật. Đã bấm: 0/3
